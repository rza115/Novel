# Style Review

Checklist teknis gaya bahasa, dicek terhadap `StoryBible/06_style_guide.md`.

## Kalimat & Diksi
- [ ] Tidak ada purple prose / deskripsi berlebihan
- [ ] Struktur "Aku X, maka aku Y" (atau pola serupa) dipakai secukupnya, tidak berlebihan jadi gimmick
- [ ] Tense konsisten sepanjang bab

## Dialog
- [ ] Dialog manusia tertangkap sepotong-sepotong, bukan adegan penuh
- [ ] Format dialog konsisten dengan bab-bab lain

## POV
- [ ] Tidak ada informasi yang secara logis tidak mungkin diketahui kucing
- [ ] Narator tidak "masuk" ke pikiran manusia secara langsung, hanya menyimpulkan dari perilaku

## Catatan Revisi
_(isi per bab)_
