# Chapter Review Checklist

Gunakan checklist ini tiap selesai draft satu bab. Bisa dipakai manual atau lewat `Prompts/critic.md` di sesi Claude Code CLI.

## Struktur Loop
- [ ] Ada momen observasi konkret di awal
- [ ] Ada refleksi/perbandingan dengan naluri hewan
- [ ] Ada ironi yang muncul secara halus, tidak dijelaskan gamblang
- [ ] Bab berhenti di titik ironi/simpulan kecil, bukan ditutup dengan moral eksplisit

## Suara Narator
- [ ] Narator tidak menghakimi manusia
- [ ] Narator tidak tahu hal-hal yang secara logis tidak mungkin dia tahu (nama lengkap orang, isi hati orang, dll — lihat batasan POV di `StoryBible/05_narrator.md`)
- [ ] Tidak ada dialog manusia yang terlalu panjang/lengkap

## Konsistensi
- [ ] Lokasi & tokoh cocok dengan `StoryBible/04_world.md` dan `Characters/supporting_characters.md`
- [ ] Tema tidak terlalu berulang dari bab-bab sebelumnya (cek `Observations/[tema].md` bagian "Bab yang Sudah Memakai Tema Ini")
- [ ] Gaya bahasa sesuai `StoryBible/06_style_guide.md`

## Setelah Review
- [ ] Update `PROJECT.md` log bab
- [ ] Update file `Observations/` terkait (tandai tema sudah dipakai di bab mana)
