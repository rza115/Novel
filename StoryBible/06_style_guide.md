# 06 — Style Guide

## Sudut Pandang
Orang pertama ("Aku"), dari sudut pandang kucing.

## Tense

## Panjang Kalimat & Ritme
- Kalimat pendek untuk observasi/fakta ("Aku lapar, maka aku mencari makan.")
- Kalimat lebih panjang untuk refleksi/ironi
- Hindari deskripsi berlebihan/purple prose — narator kucing bukan penyair, dia praktis dan sederhana secara bahasa, meski dalam secara makna

## Dialog
- Dialog manusia hadir sepotong-sepotong, tertangkap sambil lalu (bukan adegan dialog penuh dengan tag "kata dia")
- Kucing tidak pernah bicara ke manusia
- _(opsional: apakah dialog manusia ditulis pakai tanda kutip normal, atau gaya lain — italic, tanpa tanda kutip — buat kasih efek "tertangkap sepintas"?)_

## Hal yang Dihindari
- Personifikasi berlebihan (kucing terlalu manusiawi/tahu segalanya)
- Penjelasan moral eksplisit di akhir bab ("dan itulah pelajaran tentang...")
- Antagonis kartun/manusia jahat murni
- Plot device besar (misteri, kejahatan, dsb) — ini bukan thriller

## Format Penulisan Observasi → Ironi
Pola dasar (lihat `03_philosophy.md`):
1. Kucing melihat sesuatu konkret
2. Dikaitkan dengan naluri hewani sederhana
3. Dikontraskan dengan perilaku manusia
4. Berhenti di titik ironi — tanpa penjelasan lanjutan
